# 금융거래조회서 자동화 프로그램 설계 문서 (Design Document)

## 개요 (Overview)
금융거래조회서 자동화 프로그램은 금융 문서 내의 표(Table)를 자동으로 탐지하고, OCR(광학 문자 인식) 기술을 활용해 데이터를 추출한 뒤, 결과를 엑셀 파일로 변환하는 시스템입니다. 이 프로젝트는 금융 데이터 입력 작업의 효율성과 정확성을 획기적으로 높이는 것을 목표로 합니다.

## 프로젝트 구조 (Project Structure)
이 프로젝트는 유지보수와 확장성을 고려하여 다음과 같은 구조로 구성되어 있습니다.

- **root/**
  - `app.py`: Streamlit 기반의 웹 애플리케이션 진입점입니다. UI 구성 및 사용자 상호작용을 담당합니다.
  - `pyproject.toml`: Poetry를 이용한 프로젝트 의존성 및 빌드 설정 파일입니다.
  - `README.md`: 프로젝트 개요 및 사용법 설명서입니다.

- **src/**: 핵심 애플리케이션 코드가 위치합니다.
  - `__init__.py`: 패키지 초기화 파일입니다.
  - `cli.py`: 터미널 환경(CLI)에서 프로그램을 실행하기 위한 진입점입니다.
  - `config.py`: 환경 변수 및 애플리케이션 설정을 관리합니다.
  - `processor.py`: 전체 처리 흐름(PDF 로드 -> 추출 -> 저장)을 제어하는 지휘관 모듈입니다.
  - `extractor.py`: PDF에서 표와 텍스트를 추출하는 핵심 엔진입니다. (pdfplumber + PaddleOCR 하이브리드 방식)
  - `detection.py`: 이미지에서 표 영역을 탐지하는 로직을 감싸는 래퍼(Wrapper)입니다.
  - `ocr.py`: 이미지 내 텍스트를 인식하는 OCR 기능을 감싸는 인터페이스입니다.
  - `excel_writer.py`: 추출된 데이터를 엑셀 시트로 변환하고 파일로 저장하는 기능을 담당합니다.
  - `utils.py`: 로깅 설정, 정규식 파싱, 데이터 정제 등 공통 유틸리티 함수 모음입니다.

- **tests/**: 기능 검증을 위한 단위 테스트 코드가 위치합니다.
  - `test_extractor.py`: 표 추출 및 병합 로직 테스트.
  - `test_processor.py`: 전체 처리 프로세스 및 예외 처리 테스트.
  - `test_excel_writer.py`: 엑셀 생성 및 시트 저장 로직 테스트.

- **data/**: 데이터 파일 저장소입니다.
  - `samples/`: 테스트용 샘플 PDF 파일.
  - `fixtures/`: 테스트 코드에서 사용하는 고정 데이터.

- **docs/**: 프로젝트 문서화 폴더입니다.
  - `design.md`: 시스템 구조 및 기능을 설명하는 설계 문서.

- **.github/workflows/**: CI/CD 자동화 스크립트가 위치합니다.
  - `ci.yml`: 자동 테스트 및 빌드 검증 워크플로우.

## 주요 기능 (Functionality)

1. **하이브리드 데이터 추출 (Hybrid Extraction)**
   - **텍스트 PDF:** `pdfplumber`를 사용하여 텍스트 레이어를 직접 추출, 빠르고 정확한 데이터를 확보합니다.
   - **이미지(스캔) PDF:** 텍스트 레이어가 없는 경우, OpenCV 기반의 이미지 처리로 표 격자(Grid)를 탐지하고 `PaddleOCR`을 통해 텍스트를 복원합니다.
   - **표 병합 (Table Merging):** 페이지가 넘어가더라도 헤더 구조가 동일한 표는 자동으로 하나의 데이터로 병합합니다.

2. **사용자 친화적 인터페이스 (UI/UX)**
   - **Streamlit 웹 앱:** 드래그 앤 드롭 방식의 파일 업로드와 실시간 진행 상황 확인이 가능합니다.
   - **원클릭 엑셀 다운로드:** 복잡한 과정 없이 버튼 하나로 정제된 엑셀 파일을 다운로드할 수 있습니다.

3. **안정성 및 품질 관리**
   - **유효성 검사:** 파일명 규칙 검사 및 암호화된 파일 식별.
   - **로깅 시스템:** 처리 과정과 오류를 상세히 기록하여 문제 해결을 지원합니다.

## 결론 (Conclusion)
본 설계 문서는 금융거래조회서 자동화 프로그램의 1단계(MVP) 구조를 정의합니다. 이 시스템은 최신 Python 기술 스택과 OCR 기술을 결합하여, 회계 감사의 수작업 부담을 줄이고 데이터 무결성을 보장하는 강력한 도구를 제공합니다.
