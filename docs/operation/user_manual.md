# 시스템 사용자 매뉴얼

## 1. 개요
본 매뉴얼은 '금융거래조회서 키인(Key-in) 자동화 시스템'의 사용법을 안내합니다. 본 시스템은 수기로 진행되던 금융거래조회서의 데이터 입력 작업을 자동화하여, PDF 형태의 스캔본 문서에서 표 데이터를 추출하고 지정된 엑셀 템플릿으로 변환해 주는 웹 기반 도구입니다.

## 2. 화면 구성
시스템에 접속하면 나타나는 메인 페이지(SCR-01)는 크게 네 가지 핵심 영역으로 구성됩니다.

* **파일 업로드 영역 (SCR-01-001):** 변환할 금융거래조회서 PDF 파일을 선택하고 업로드하는 영역입니다.
* **처리 설정 영역 (SCR-01-004):** 업로드된 문서에서 OCR(문자 인식)을 수행할 마지막 페이지 번호를 설정합니다. (기본값: 4페이지, 최소 시작 페이지: 3페이지)
* **실행 영역 (SCR-01-002):** 설정이 완료된 후 데이터 추출 파이프라인(전처리 및 OCR)을 가동하는 '처리 시작' 버튼이 위치합니다.
* **결과 다운로드 영역 (SCR-01-003):** 처리가 완료된 후 생성된 엑셀(.xlsx) 파일을 내려받을 수 있는 영역입니다.

## 3. 작업 수행 절차

**Step 1. 금융거래조회서 PDF 준비 및 업로드**
1. 시스템 메인 화면에 접속합니다.
2. 화면 중앙의 [파일 업로드] 버튼을 클릭하거나, 준비된 PDF 파일을 드래그 앤 드롭하여 업로드합니다.
3. 파일명은 시스템이 자동으로 인식하므로(예: `감사대상회사_숫자_조회처.pdf`), 지정된 파일명 규칙을 준수하여 업로드해야 합니다.

**Step 2. OCR 처리 페이지 범위 설정**
1. 파일이 정상적으로 업로드되면 하단의 '처리 설정 영역'이 활성화됩니다.
2. 금융상품 및 대출거래 내역이 포함된 마지막 페이지 번호를 입력합니다. (표준 금융거래조회서 양식에 따라 3페이지부터 인식을 시작합니다.)

**Step 3. 데이터 변환 실행**
1. [처리 시작] 버튼을 클릭합니다.
2. 시스템이 이미지 변환, 노이즈 제거, 데이터 추출(OCR) 작업을 순차적으로 수행합니다. 작업이 진행되는 동안 화면에 진행 상태가 표시됩니다.

**Step 4. 결과 검토 및 엑셀 파일 다운로드**
1. 처리가 완료되면 [엑셀 다운로드] 버튼이 생성됩니다.
2. 버튼을 클릭하여 결과물(.xlsx)을 PC에 저장합니다.
3. 다운로드한 엑셀 파일을 열어 원본 조회서의 내용이 템플릿의 올바른 위치에 기입되었는지 확인합니다.

## 4. 제약 사항 및 주의 사항

시스템의 안정적인 동작과 정확한 데이터 추출을 위해 다음 사항을 반드시 유의해 주시기 바랍니다.

### 4.1. 입력 파일 제약 (FUNC-001)
* **허용 확장자:** `.pdf` 파일만 업로드 가능합니다. 이미지 파일(.jpg, .png 등)은 지원하지 않습니다.
* **파일 용량 및 개수:** 파일 1개당 최대 **300MB**까지만 허용되며, 한 번에 최대 **10개**의 파일만 동시 처리가 가능합니다.
* **보안 문서 제한:** 비밀번호가 설정되어 암호화된 PDF는 시스템이 읽을 수 없으므로, 업로드 전 반드시 암호를 해제해야 합니다.
* **최소 페이지 요건:** 페이지 수가 3장 미만인 문서는 정상적인 금융거래조회서로 간주하지 않아 처리가 제한됩니다.

### 4.2. 데이터 검증 및 회계사 검토 의무
* **합계 불일치:** 본 시스템의 목적은 문서에 적힌 내용을 그대로 정확히 추출(Key-in)하는 것입니다. 원본 문서 자체에 기재된 금액의 총계가 틀리거나 계산이 맞지 않더라도, 시스템은 이를 임의로 수정하거나 합산하여 교정하지 않습니다.
* **항목 누락:** 원본 조회서에 필수 표 항목(예: 9번 항목 누락 등)이 비어있거나 누락된 경우, 시스템은 발견된 내용까지만 추출합니다.
* **최종 책임:** 변환된 엑셀 데이터의 논리적 오류 판단과 최종 검증은 담당 회계사의 고유 업무 영역이므로, 다운로드 후 반드시 마스터 파일과 대조하는 과정을 거쳐야 합니다.
