# OCR 엔진 및 데이터 추출 상세 설계서

## 1. 개요

본 문서는 금융거래조회서 PDF에서 표 데이터를 추출하기 위한 전처리, OCR 인식, 그리고 후처리 단계의 상세 로직을 정의합니다. 복잡한 형태의 스캔본 문서나 노이즈가 있는 이미지에서도 정확하게 데이터를 추출하여 구조화하는 것을 목표로 합니다.

## 2. 이미지 전처리

`src/core/preprocessor.py`에서 수행되는 이 단계는 OCR 엔진이 표 내부의 텍스트를 가장 잘 인식할 수 있도록 이미지를 최적화하는 과정입니다. (FUNC-003)

### 2.1. 기본 최적화

* **그레이스케일 및 업스케일링:** 컬러 이미지를 흑백으로 변환하고, 해상도를 2배로 업스케일링하여 작은 글씨의 선명도를 확보합니다.
* **이진화 및 영역 팽창:** 적응형 이진화를 적용하여 음영을 제거하고, 텍스트와 선의 영역 팽창을 3회 반복하여 끊어진 선이나 희미한 글자를 보완합니다.

### 2.2. 표 영역 탐지

* **외곽선 탐지:** 전처리된 이미지에서 외곽선을 탐지합니다.
* **유효 면적 필터링:** 전체 페이지 면적의 1% 이상을 차지하는 외곽선만 유효한 표 영역으로 간주하여 노이즈(스탬프, 수기 메모 등)를 배제하고 해당 영역만 크롭합니다.

### 2.3. 세로선 제거 로직

* **세로선 탐지 및 마스킹:** 표 내부의 세로선이 텍스트(특히 숫자 1이나 I 등)와 혼동되는 것을 방지하기 위해, 세로선을 탐지하여 흰색으로 덮어쓰는 작업을 수행합니다. 이 과정을 통해 OCR 엔진의 오인식을 대폭 줄입니다.
* **읽기 순서 정렬:** 문서의 기본 읽기 순서(위에서 아래, 좌에서 우)를 기준으로 크롭된 다중 표 이미지를 정렬합니다.

## 3. OCR 텍스트 추출

`src/core/ocr_engine.py`는 전처리된 이미지에서 실제 텍스트와 좌표를 추출합니다.

### 3.1. 엔진 선정 및 특징

* **PaddleOCR 사용:** 한글 인식률과 복잡한 표 인식 환경에서의 성능 테스트 결과, EasyOCR과 Tesseract보다 높은 정확도를 기록하여 최종 채택되었습니다. (ADR-003, ADR-006)
* **출력 데이터 표준화 (ADR-008):** 특정 OCR 프레임워크에 종속되지 않도록, 추출된 데이터를 시스템 내부 표준 규격(`[텍스트, [x1, y1, x2, y2], 신뢰도]`)으로 매핑하여 반환합니다.

## 4. 데이터 그룹화 및 후처리

`src/core/postprocessor.py` 및 `src/utils/` 모듈은 비정형 OCR 데이터를 논리적인 표 형태로 재구성합니다.

### 4.1. 좌표 기반 행/열 그룹화

* Bounding Box의 Y좌표를 기준으로 동일 선상에 있는 텍스트들을 하나의 행으로 그룹화합니다.
* X좌표를 기준으로 열을 정렬하여 테이블 구조를 복원합니다.

### 4.2. 다중 페이지 표 병합 (ADR-007)

* 하나의 표가 여러 페이지에 걸쳐 분할된 경우, 이전 페이지 하단의 표 속성 개수와 현재 페이지 상단의 표 속성 개수를 비교합니다.
* 속성 개수가 일치하고 논리적 연속성이 인정되면 동일한 표로 간주하여 데이터를 병합합니다.

### 4.3. 텍스트 보정 및 예외 처리

* **유사 문자 보정 (REQ-F-005):** '0'과 'O', '1'과 'I' 등 문맥상 명확한 오인식 문자를 `validators.py` 규칙에 따라 자동 교정합니다.
* **공란 처리 (REQ-F-004):** 조회서 특성상 의도적으로 비워둔 셀(예: 대출 잔액이 없는 경우 등)을 오류나 누락으로 처리하지 않고 정상적인 빈 데이터(None/Null)로 유지합니다.
* **불필요한 앵커 텍스트 무시:** `Sample.csv` 규칙에 따라 셀 외곽에 세로로 적힌 텍스트(예: "전자어음", "수표·어음")는 추출 데이터에서 제외합니다.
